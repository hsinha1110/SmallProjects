# Expense Tracker 💰

Expense Tracker is a React Native mobile application designed to help users manage and track their daily expenses in a simple and organized way.

## ✨ Features

- Add and manage expenses
- Categorize expenses
- View expense lists
- Category-based expense tracking
- Reusable UI components
- Custom category dropdown
- Expense summary
- Clean and responsive interface
- TypeScript-based implementation

## 🛠️ Tech Stack

- React Native
- TypeScript
- React Native CLI
- React Navigation
- Reusable Components
- Custom Styling

## 📱 Main Features

### Expense Management

Users can view and manage their expenses with relevant information such as:

- Expense title
- Amount
- Category
- Date

### Categories

Expenses can be organized using different categories to make tracking easier.

### Reusable Components

The application follows a reusable component-based architecture to keep the code clean and maintainable.

## 🎯 Purpose

This project was created to practice and demonstrate React Native concepts including TypeScript, reusable components, list rendering, form handling, category filtering, and mobile UI development.

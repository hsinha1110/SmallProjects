# Notes App 📝

Notes App is a React Native mobile application that allows users to create, edit, delete, and manage their personal notes with a simple and clean user interface.

# DEMO

https://github.com/user-attachments/assets/c5f84227-cb88-4663-81cd-55c51190ad5f

## ✨ Features

- Create new notes
- Edit existing notes
- Delete notes
- View note details
- Search notes
- Organized note listing
- Reusable UI components
- Form handling and validation
- Clean and responsive UI
- TypeScript-based implementation

## 🛠️ Tech Stack

- React Native
- TypeScript
- React Native CLI
- React Navigation
- Reusable Components
- Custom Styling

## 📱 Main Screens

- Notes Home
- Add Note
- Edit Note
- Note Details

## 🎯 Purpose

This project was created to practice and demonstrate React Native concepts including CRUD operations, navigation, TypeScript, reusable components, form handling, list rendering, and mobile UI development.
